## Contenido

- `index.html`: portada centrada, logo de la UTD, datos y enlaces.
- `images/logo-utd.png`: logo extraído del PDF de evaluación.
- `images/foto-profesional.svg`: foto proporcionada por el estudiante en un marco
  cuadrado de 400 x 400 píxeles. El PNG original está incrustado sin alterar sus
  bytes ni deformar sus proporciones. Su resolución original es 113 x 129.
- `diagrams/`: tres diagramas de flujo (proceso principal, clientes y dinero)
  y tres diagramas de casos de uso (programador, usuario y actor bancario).
  Cada diagrama tiene su página y su imagen SVG descargable.
- `game/`: mini juego de plataformas, con instrucciones y controles en español.

Los diagramas describen un sistema de gestión de servicios. El PDF de evaluación
pide la interfaz, pero no define el contenido de los diagramas ni exige programar
un juego. Se añadieron ejemplos y un mini juego original para que los destinos
funcionen. Si el profesor exige los diagramas trabajados en clase, deben sustituirse
por esos contenidos. El juego conserva el nombre Mario usado en la referencia.

## Usarlo y modificarlo

Descarga el código desde el repositorio con la opción de descargar ZIP. Extrae
el archivo y abre `index.html` en tu navegador. Puedes abrir la carpeta en
Visual Studio Code para modificarla. No requiere instalar dependencias.

Para cambiar la foto, usa otra imagen proporcionada por el estudiante. Mantén
un marco de 400 x 400 y conserva las proporciones. Para cambiar un diagrama,
modifica su SVG y su descripción en la página HTML correspondiente.

## Partes del HTML

- Los títulos se escriben con etiquetas como `h1`, `h2` y `h3`.
- `img` muestra una imagen; `src` indica su archivo y `alt` la describe.
- `a` crea un enlace a otra página.
- `form` y `button` permiten abrir los diagramas mediante botones.
- `style` contiene los estilos sencillos de tamaño, tipografía y alineación.

La fuente de los requisitos académicos es el PDF de evaluación proporcionado
por el estudiante. La traducción al español y el uso del nombre completo y la
fotografía fueron indicados por el estudiante para este trabajo.
